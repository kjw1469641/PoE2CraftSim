# PoE2CraftSim

A free, unofficial crafting simulator for Path of Exile 2. Pick up a currency, apply it to an item, and see the possible outcomes and their chances. Supports essences, omens, desecration, runes, distilled emotions, a probability table, and simulation over thousands of runs. Available in Korean and English.

## Download

Get the latest version from the Releases tab: https://github.com/kjw1469641/PoE2CraftSim/releases

Unzip anywhere and run PoE2CraftSim.exe . Windows only, no installation needed.
